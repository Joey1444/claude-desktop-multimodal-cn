# Claude Desktop 接非官方模型完全指南：文本走 CC Switch，图/视频/语音走 OpenRouter

> **本文所有步骤在 Windows 11 + Claude Desktop 上实测跑通**，踩过的坑在文末，可直接抄。

---

## 先说你现在的处境

Claude Desktop 挺好用，但有两个硬伤：

1. **只能用 Anthropic 自己的模型**——想换成 DeepSeek、Kimi、GLM 省钱？没入口。
2. **它不能出图、不能出视频、不能配音**——你只能跟它聊天。

网上教程要么只解决第一个，要么只解决第二个，而且**大量在教你手改 JSON**。

这篇给一个**完整方案**：两条互不冲突的通道，一次配好。

---

## 核心认知：这是两条独立的通道

| 你想干的事 | 用什么 | 原理 |
|---|---|---|
| 让 Claude 用 DeepSeek / Kimi / GLM 说话 | **CC Switch** | 桌面 App 一键改连接信息，或起本地代理做格式转换 |
| 让 Claude 出图 / 出视频 / 配音 / 转写 | **OpenRouter + MCP** | 把 OpenRouter 的接口挂成 Claude 的工具 |

**关键**：它们不抢位置，**可以同时开**。

原因是它们解决的是不同层面的问题——CC Switch 管「Claude 用哪个大脑说话」，OpenRouter 管「Claude 手边有哪些工具」。一个是换发动机，一个是加装工具箱。

---

## 通道一 · 文本模型：CC Switch

### 为什么推荐它

[CC Switch](https://github.com/farion1231/cc-switch) 是个开源桌面应用（MIT），支持 Claude Code、**Claude Desktop**、Codex、Gemini CLI 等十来个工具。

它解决的是**手改配置**这个痛点。官方原话：

> 切换只替换连接信息（endpoint、key、model），**你自己加的插件、hooks、MCP、注释原样保留**。

而且**改写配置文件前自动备份**，首次启动会**自动导入**你已有的配置。这一点很关键——不用担心它把你辛苦配的东西冲掉。

### 装

去 [Releases](https://github.com/farion1231/cc-switch/releases) 下 `CC-Switch-v{版本}-Windows.msi`。

首次启动它会扫描并导入你现有的 Claude Code / Codex 配置，为每个工具（含 Claude Desktop）加一个官方 provider。

### 用

在 Claude Desktop 那一页选一个 provider、填 key、点切换。完事。

### 三个必须知道的点 ⚠️

1. **Claude Desktop 切换后必须完全重启 App**（Claude Code 不用）
2. **Claude Desktop 只支持 `Direct` 和 `Model Mapping` 两种模式**；选 `Model Mapping` 请求会走它的本地路由
3. **在 Claude Desktop 页面点开的 MCP / Skills 面板，实际作用于 Claude Code**——别被界面位置骗了

## 通道二 · 全模态：OpenRouter MCP

CC Switch 管文本。图、视频、语音这些它管不了——那是 OpenRouter 的活。

### OpenRouter 到底有哪些模态

很多人以为 OpenRouter 就是个"多模型聊天 API"。不是。它按 `output_modalities` 分了这些（数字是实测值，会变）：

| 模态 | 数量 | 接口 |
|---|---|---|
| text | 458 | `/api/v1/chat/completions` |
| image | 61 | `/api/v1/images` |
| video | 30 | `/api/v1/videos` |
| speech（TTS） | 32 | `/api/v1/audio/speech` |
| transcription（STT） | 25 | `/api/v1/audio/transcriptions` |
| embeddings | 37 | `/api/v1/embeddings` |
| rerank | 9 | `/api/v1/rerank` |
| **decisions** | 19 | **`/api/alpha/decisions`** ⚠️ 不在 `/v1` 下 |

「decisions」你可能没听过：**这类模型不返回文本，只返回概率**。适合做「这个标题够不够抓人」这种判定。

### 怎么接进 Claude Desktop

**第一步，装主体 MCP server**——推荐现成的 [stabgan/openrouter-mcp-multimodal](https://github.com/stabgan/openrouter-mcp-multimodal)（19 个工具，覆盖 chat / 图片 / 视频 / 语音 / 转录 / 重排）：

```bash
claude mcp add --scope user --transport stdio openrouter -- npx -y @stabgan/openrouter-mcp-multimodal
```

**第二步，补上它没有的两类**（embeddings / decisions）：

```bash
claude plugin marketplace add Joey1444/openrouter-models-skill
claude plugin install openrouter-models@openrouter-models
```

顺带你还会得到一条 `/openrouter-models:models` 命令，专门用来**挑模型**（下面细说）。

---

## 最实用的部分：怎么挑到「真免费」的模型

这是最容易踩坑的地方，也是本文最值钱的一段。

**别去官网一个个翻。** 装完上面的插件后直接在 Claude 里打：

```
/openrouter-models:models                 # 每类模态有多少、几个免费
/openrouter-models:models image --free    # 图片里哪些真免费
/openrouter-models:models speech          # 语音全部，便宜在前
```

### 「真免费」的判据（实测得出）

很多人（包括我）第一反应是看 `pricing.prompt` 是不是 0。**这是错的。**

真实计费藏在 `image_output` 和 `image_token` 里。我实测对比过：

```
bytedance-seed/seedream-5-0-flash → prompt=0, completion=0, image=0
                                    但 image_token=0.0000043  ← 其实收费！
inclusionai/ming-image-0.1-design → 全部字段为 0            ← 真免费
```

所以正确判据是：

- ✅ **id 带 `:free`** 或 **pricing 全部字段为 0** → 真免费
- ❌ 只看 `prompt`/`completion` → 会把收费模型当成免费
- ⚠️ **视频类定价压根不在接口里** → 一律标「价格未知」，当收费对待

### 三个实测可用的免费模型

| 用途 | 模型 | 备注 |
|---|---|---|
| 出图 | `inclusionai/ming-image-0.1-design` | 出 **1440×2560**，实测质量够做人物定妆 |
| 配音 | `fish-audio/s2.1-pro-free:free` | 多数教程推荐的默认免费 TTS **已经 404 了** |
| 文本 | `google/gemma-4-31b-it:free` | 会限流，重试即可 |

**注意**：免费模型会失效。**用之前先试一次**，别直接写进生产流程。

## 实测踩坑清单（都是真撞过的）

1. 🔴 **`decisions` 在 `/api/alpha/`，不在 `/api/v1/`**。官方 OpenAPI 只声明了 `/api/v1`，但 `/v1/alpha/decisions` 返回 404——文档和实现不一致。
2. 🔴 **列模型必须带 `?output_modalities=<模态>`**。不带过滤只返回文本模型（458 个），你会以为 OpenRouter 没有出图模型。
3. 🔴 **Windows GUI 里找不到 `npx`**。Claude Desktop 从系统 PATH 启动，拿不到你终端里的 `npx`。解法：用**绝对路径直跑** node。
4. 🔴 **免费 TTS 默认模型已失效**，报文是 `No endpoints found`。
5. ⚠️ **反斜杠会被吃掉**。手写 `D:\apps\x` 在某些环节会变成转义符（`\a` = 响铃）。**路径统一用正斜杠**。
6. ⚠️ **CLI 传中文参数会被 GBK 破坏**，报 `Request contains invalid Unicode text`。改走 Claude 工具调用。
7. ⚠️ **CC Switch 切完 Claude Desktop 不重启 = 看着像没生效**。

## 成本

| 项 | 说明 |
|---|---|
| CC Switch | 免费开源 |
| OpenRouter 文本 | 按 token 计，**有免费模型**但会限流 |
| OpenRouter 出图 | 免费模型可跑通 |
| OpenRouter 视频 | **基本都要钱**，且接口不给定价 |
| 真实花费 | 看响应里的 `usage.cost` 字段，那是权威数字 |
